# NeuralCore

Библиотека для компьютерного зрения, построенная на базе [Supervision](https://github.com/roboflow/supervision).

## Структура
- `libs/supervision` — форк оригинальной библиотеки (субмодуль).
- `neuralcore/` — ваши расширения и доработки.

## Установка
```bash
git clone --recursive git@github.com:nrldev/neuralcore.git
cd neuralcore
pip install -e .
```
